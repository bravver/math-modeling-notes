## 目录约定

仓库是「**一篇文章 = 一个文件夹**」的平铺结构，刻意不套过多层级，方便随手把一场比赛的产物整体丢进来。推荐文件夹里至少包含：

```
<TIM-竞赛-题号/队号>/
├─ README.md            # 文章页：题面回顾 / 方法 / 结果 / 复盘 / 文件清单
├─ <题目>.pdf           # 竞赛题目（若有）
├─ <论文>.pdf           # 提交的论文
├─ <支撑材料>.zip       # 官方提交的支撑材料（原样保留）
└─ ...                  # 其它原始材料（附件、代码等）
```

新增文章时，**原文件夹怎么放就怎么放**，不必强制拆分；只要补一篇 `README.md` 并在上面索引表里加一行即可。

---

## 新增一篇文章（模板）

以后来了新赛题，照下面四步走：

1. 在本仓库根目录新建文件夹，命名建议保留官方编号，例如 `2027-美赛-MCM-A-1234567/`；
2. 把该场比赛的题目 pdf、提交论文 pdf、支撑材料 zip 等原始文件放进去；
3. 复制下面模板，写一篇 `README.md` 放到该文件夹里：

```markdown
# <文件夹名> · <竞赛全称> <题号>

| 项 | 内容 |
|---|---|
| 竞赛 | <名称（届次 / 年份）> |
| 题目 | <题号> · <题目标题> |
| 队伍编号 | <官方编号> |
| 论文标题 | <作品/论文标题> |
| 数据/材料 | <所用数据集与日期范围> |
| 状态 | 已参赛 · 获奖情况<待补/…> |

## 题面回顾
…
## 我的方法
### 问题一 … ### 问题二 … ### 问题三 …
## 主要结果
…（表格或要点）
## 复盘与心得
…
## 文件清单
| 文件 | 说明 |
|---|---|
…
```

4. 回到根目录 `README.md`，在**文章索引**表格里加一行，并把「目录约定」保持一致。

## 说明与约定

- **材料一律保留原样**：支撑材料是比赛提交原件，未做二次整理或裁剪；论文中的措辞、结论与署名均以提交稿为准。
- **数据与复现**：若支撑材料含数据/结果表，一般可在文章页找到「复现入口」的说明；代码缺失的比赛会在文章页注明。
- 论文 PDF 若带权限保护（限制复制 / 打印），属提交版本身自带，仓库不做改动。
