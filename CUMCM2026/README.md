## 研究内容

机器狗在测向误差有界、干扰源位置与接收范围未知的情况下，如何完成发现、定位、补测、移动与清除。

| 问题 | 主要方法 | 阅读重点 |
| --- | --- | --- |
| 定位与覆盖判定 | 半平面裁剪、旋转卡壳、最小包围圆 | 区域直径和覆盖半径的区别 |
| 第二检测点设计 | 鲁棒极小极大、候选域与交换迭代 | 最坏情景下仍保证接收 |
| 全向源普查 | 七点覆盖、逐频道状态、2-opt 路径优化 | 先保证发现，再优化行程 |
| 混合定向源 | 凸包覆盖、21 点普查、主动补测 | 无信号不等于没有干扰源 |
